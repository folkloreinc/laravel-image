# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Include the affected version, the configuration involved (source driver, route options) and the steps to reproduce. We'll acknowledge the report, work on a fix, and publish an advisory once a release is available.
